Anthropic's Claude apps gateway enables enterprise deployment of Claude Code on Google Cloud, centralizing governance via OIDC identity management, policy enforcement, telemetry, and spending limits. It routes inference through Cloud Run, integrating with Agent Platform while keeping inference inside the customer's GCP project perimeter.
